# pragmatical.ai

Static HTML site for Pragmatical AI — applied AI for the systems your business depends on.

## Structure
- `index.html` — homepage
- `code-doctor.html` — flagship product (CodeDoctor)
- `contract.html`, `fleet.html`, `data.html` — product lines (in development)
- `about.html` — company + team
- `contact.html` — engage form
- `styles.css` — design system

## Stack
Pure static HTML + CSS. No build step. Fonts via Google Fonts (Instrument Serif + Instrument Sans + JetBrains Mono).

## Preview
```
python3 -m http.server 8080
```
