# Pragmatical AI visual language proposal

7 September 2026. A selected design direction based on the positioning document and the user's request for stronger colour and a professional visual identity. This is a brand study; the application has not been restyled in this turn.

Open [the rendered study](brand-study.png), [the browser version](brand-study.html), or [the vector board](brand-study.svg).

## Direction

Cobalt gives the identity a clear, energetic anchor. Ink and white provide contrast and reading space. Ice blue supports technical illustrations. Signal orange punctuates selected points in those illustrations; it is not a second primary brand colour or a default button fill.

The proposed geometric P symbol uses a connected path and a separate output point. It is a design exploration, not a finished or cleared trademark. The logo treatment uses a geometric display face distinct from the reading face. The next refinement should optically adjust the wordmark and symbol together, including monochrome and small-size applications.

## Palette and roles

| Token | Light | Dark | Use |
| --- | --- | --- | --- |
| Canvas | #FFFFFF | #111827 | Main page |
| Primary text | #172033 | #F5F7FC | Headings and body |
| Secondary text | #526078 | #BECADD | Explanations and captions |
| Brand/action | #2457F5 | #91ADFF | Primary actions and selected paths |
| Supporting surface | #EEF3FF | #1D293E | Diagrams and secondary regions |
| Signal | #E87945 | #E87945 | Sparse graphic detail, not small text on white |

Keep semantic error, warning and success colours separate from the brand palette. Do not use hue alone to express a diagram relationship or status. Use labels, line styles and placement as well.

## Type and composition

- Space Grotesk for display and the initial wordmark study; Inter for reading and interface labels.
- A limited scale with clear roles. Large display copy establishes the point of view; substantive supporting copy explains the technology.
- Open page structure, precise rules, modest corner radii and deliberate alignment. Avoid enclosing every statement in a card.
- A light page is the default study. Dark mode uses the same composition with calibrated surfaces and accents.

## Visual grammar

Use rendered interfaces, topology diagrams, labelled execution paths and deployment illustrations to communicate actual capabilities. The study demonstrates this with the lightweight SSR Worker framework connecting rendered web output, AI capabilities and automation. Its Cloudflare layer is explicitly conceptual, reflecting the intended integration rather than claiming complete shipping behaviour.

Build subsequent illustrations around Studio creation, system discovery, migration and service/agent execution. Use real captures where available and label conceptual diagrams. Contract Vetting receives a compact supporting product story, approximately 10–15% of the narrative.

The board demonstrates visual language, not the final homepage information architecture or copy. Its navigation and hero are illustrative applications of the identity; the full website must follow the content depth in [the positioning document](../company-positioning-and-capabilities.md).

## Verification scope

The main colour pairs have been checked with WCAG relative luminance calculations. Text/control accessibility still needs validation in the implemented components at actual sizes and states. The exported PNG provides stable typography; the HTML loads the specified Google Fonts. The standalone SVG can fall back to installed fonts when opened separately.
